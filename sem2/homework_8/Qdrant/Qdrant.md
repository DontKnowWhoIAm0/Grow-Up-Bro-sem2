## Qdrant

### Задание 1–4. Запуск через Docker

Клонируем репозиторий
```bash
git clone https://github.com/ZhenShenITIS/hw-qdrant.git
cd hw-qdrant
```

Запускаем контейнер
```bash
docker compose up -d --build
```

Открываем «http://localhost:8080/»
